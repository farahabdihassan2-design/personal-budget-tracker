# My Budget Tracker

## Description
A responsive personal budget tracking web application built as part of the PLP Academy Web Development Fundamentals program. This project helps users monitor their income, manage daily expenses, and organize financial records cleanly in one place.

## What Was Built & Features
* **Semantic HTML5 Structure (`index.html`):** Organizes the application into clear structural sections, including header branding, an interactive expense entry form, and a recent transactions ledger.
* **Working Form Upgrade:** Features a complete `<form>` element containing text inputs, validated numeric fields (`min="0"`, `step="0.01"`), and a category selection dropdown with multiple options.
* **Multimedia Integration:** Incorporates vector iconography and embedded multimedia elements rendering cleanly across standard browsers.
* **Advanced CSS Styling (`style.css`):** Utilizes modern layout techniques and implements **all 5** advanced CSS selectors:
  1. Input focus pseudo-classes (`input:focus`)
  2. Position pseudo-classes (`tr:nth-child(even)`)
  3. Negation pseudo-classes (`input:not()`)
  4. Direct child selectors (`>`)
  5. Descendant selectors for table cell formatting

## How to Run Locally
1. Clone or download this repository.
2. Open the project folder in **Visual Studio Code**.
3. Launch the project using the **Live Server** extension to view it live in your browser at `http://127.0.0.1:5500`.
